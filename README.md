# Image Compressor

이미지를 업로드하고 원하는 최대 파일 용량 이하로 압축하여 다운로드할 수 있는 웹 서비스입니다.

## 프로젝트 목표

이 프로젝트의 가장 중요한 목표는 복잡한 기능을 빠르게 만드는 것이 아니라, 이미지 업로드부터 압축, 다운로드까지의 전체 동작 과정을 직접 이해하는 것입니다.

## 프로젝트 배경

온라인 자격증 제출이나 각종 서류 업로드 시 "500KB 이하", "1MB 이하"와 같은 파일 크기 제한 때문에 이미지를 여러 번 수정해야 하는 경우가 많습니다.

이 서비스는 사용자가 원하는 최대 파일 용량을 입력하면 자동으로 이미지를 압축하여 이러한 불편을 해결하는 것을 목표로 합니다.

## 핵심 기능 (MVP)

1. JPEG 이미지를 업로드한다.
2. 원하는 최대 파일 용량(KB)을 입력한다.
3. 서버가 이미지 품질을 조절하여 목표 용량 이하로 압축한다.
4. 압축된 이미지를 다운로드한다.

## MVP에서 하지 않는 것

* 회원가입 및 로그인
* 데이터베이스
* 여러 이미지 동시 처리
* PNG 및 WebP 압축
* 이미지 편집 기능
* 클라우드 저장
* AI 기능
* 복잡한 UI

## 기술 스택

* Frontend: React + TypeScript + Vite
* Backend: FastAPI
* Image Processing: Pillow
* Development: GitHub Codespaces

## 학습 목표

이 프로젝트를 통해 다음 내용을 이해하는 것을 목표로 합니다.

* 브라우저에서 파일 업로드하는 과정
* multipart/form-data 요청
* FastAPI UploadFile
* Pillow를 이용한 이미지 처리
* JPEG 품질(Quality)의 의미
* 파일 크기(Byte, KB, MB)
* 메모리에서 이미지 저장하기
* HTTP 파일 응답
* Blob 다운로드
* 프론트엔드와 백엔드의 요청/응답 흐름

## 완료 조건

다음 흐름이 정상적으로 동작하면 MVP를 완료한 것으로 판단합니다.

이미지 선택 → 목표 용량 입력 → 압축 요청 → 서버 압축 → 다운로드
