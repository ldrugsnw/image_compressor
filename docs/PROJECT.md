# Image Compressor 프로젝트 명세

## 1. 문제 정의

많은 웹사이트는 업로드 가능한 이미지 용량을 제한합니다.

사용자는 이미지 편집 프로그램을 직접 실행하지 않고도 원하는 용량 이하로 이미지를 압축할 수 있어야 합니다.

## 2. 대상 사용자

* 자격증 제출
* 취업 지원
* 학교 과제 제출
* 온라인 문서 업로드

등에서 이미지 용량을 줄여야 하는 사용자

## 3. 핵심 사용자 흐름

1. 사용자가 JPEG 이미지를 선택한다.
2. 프론트엔드는 원본 파일명과 원본 용량을 표시한다.
3. 사용자가 목표 용량(KB)을 입력한다.
4. 사용자가 압축 버튼을 누른다.
5. 프론트엔드는 이미지와 목표 용량을 FastAPI로 전송한다.
6. 백엔드는 입력값을 검증한다.
7. 백엔드는 JPEG 품질을 조절하며 이미지를 압축한다.
8. 목표 용량 이하가 되면 압축을 종료한다.
9. 압축된 이미지를 반환한다.
10. 프론트엔드는 다운로드 버튼을 제공한다.

## 4. API 초안

### 이미지 압축

POST /images/compress

Content-Type

multipart/form-data

요청

* file
* target_size_kb

응답

* 압축된 JPEG 이미지

예외 상황

* 파일이 없음
* 이미지가 아님
* JPEG 형식이 아님
* 목표 용량이 0 이하
* 손상된 이미지

## 5. MVP 구현 순서

### 1단계

FastAPI 서버 실행

### 2단계

이미지 업로드 받기

### 3단계

원본 이미지 정보 확인

* 파일 크기
* 이미지 크기

### 4단계

JPEG 품질을 지정하여 저장하기

### 5단계

압축된 이미지 반환하기

### 6단계

React에서 FormData 전송

### 7단계

다운로드 구현

### 8단계

목표 용량을 입력받아 자동으로 품질을 조절하는 알고리즘 구현

## 6. 구현 원칙

MVP에서는 JPEG만 지원합니다.

품질(Quality)을 조절하여 목표 용량 이하로 만드는 기능만 구현합니다.

해상도 변경, 이미지 편집, AI 기능은 구현하지 않습니다.
